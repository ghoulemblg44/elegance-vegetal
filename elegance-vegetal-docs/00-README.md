# Élégance Végétal — Documentation de Cadrage Projet

Ce dossier contient l'analyse et le plan professionnel complet du projet e-commerce
**Élégance Végétal** (vente de fleurs, bouquets, plantes et compositions florales en ligne),
réalisés avant toute écriture de code.

## Principes directeurs du projet

- Frontend et backend strictement séparés
- Site responsive (ordinateur et mobile)
- Design moderne, élégant, premium et naturel
- Architecture facile à maintenir et à faire évoluer
- Développement progressif par phases (pas de "big bang")

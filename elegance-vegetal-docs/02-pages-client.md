# 2. Pages nécessaires — Client

| Page | Rôle |
|---|---|
| Accueil | Mise en avant des produits phares, univers de marque, occasions du moment |
| Catalogue / Catégorie | Liste filtrable et triable des produits |
| Fiche produit | Détail complet du produit, personnalisation, ajout au panier |
| Panier | Récapitulatif des articles, modification des quantités |
| Checkout (tunnel de commande) | Adresse, créneau de livraison, paiement — idéalement en une seule page fluide |
| Confirmation de commande | Récapitulatif final et informations de suivi |
| Compte client (dashboard) | Historique de commandes, adresses, favoris |
| Connexion / Inscription | Authentification |
| Recherche (résultats) | Résultats de recherche dynamiques |
| À propos | Histoire de la marque, valeurs (naturel, premium, artisanal) |
| Blog / Conseils | Articles sur l'entretien des plantes et fleurs |
| Contact | Formulaire de contact et informations pratiques |
| FAQ / Livraison / CGV | Pages de réassurance et d'information légale |
| Page 404 | Page d'erreur personnalisée, cohérente avec l'identité visuelle |
